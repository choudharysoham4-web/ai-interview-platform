# AI Interview Pro

AI Interview Pro is an AI-powered interview preparation platform built using React, Spring Boot, JWT Security, Gemini AI, Voice Recognition, Resume Analysis, and PDF Export.

## Features
- AI interview question generation
- JWT login and registration
- Voice interview mode
- AI answer evaluation
- Resume upload and analysis
- PDF export
- Question history
- Spring Security integration

## Tech Stack
Frontend: React  
Backend: Spring Boot  
Security: JWT + Spring Security  
Database: MySQL / H2  
AI: Gemini API  
Tools: Git, GitHub, Docker, Postman

## Project Status
Frontend deployed on Vercel.  
Backend runs locally and is Docker-ready.
